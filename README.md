# pinlex.work — Экосистема цифровых визиток (Build 2.6 Final Hotfix)

Единая кроссплатформенная экосистема для создания, кастомизации и мгновенной онлайн-синхронизации цифровых визиток (включая 100% надежное сохранение аватарки и шапки визитки через тройной локальный кэш и облачный движок `KeyVal Media Chunk Engine`, все вкладки, цифры и факты, вид соцсетей и GIF-обложки) между **компьютером** и **смартфоном (iPhone / Android)**.

## 🔥 Ключевые возможности Build 2.2

### 1. Реальная облачная синхронизация ПК ↔ Телефон
- Оба билда (`index.html` на ПК и `mobile.html` на телефоне) и витрина (`card.html`) подключены к единому облачному слоту синхронизации (`MASTER_CLOUD_SLOT`).
- Любое изменение текста, контактов, шрифта, шаблона или GIF-анимации автоматически синхронизируется с облаком через 1.4 секунды (или мгновенно по кнопке **«☁️ Сохранить онлайн»**).
- Второе устройство автоматически подхватывает изменения в реальном времени каждые 4.5 секунды и при открытии страницы.

### 2. Красный бейдж `ADMIN` с полным доступом
- Для владельца активен статус **`ADMIN`** (красный бейдж `#ef4444` с неоновым свечением в шапке студии и на самой визитке).
- Все функции `PRO` (загрузка анимированных `.gif` в аватар и шапку, живые обложки, неоновая рамка, отключение водяного знака) разблокированы по умолчанию.
